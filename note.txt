Скрипт установки окружения на новый сервер
Реально используется в DevOps — когда поднимаешь новую ВМ, 
нужно быстро всё настроить.
Что будет делать:

Читать список пакетов из файла packages.txt
Устанавливать каждый через apt
Проверять успешность установки
Писать лог что установилось, что нет

По пути освоишь:

Проверку прав root ($EUID)
Работу с apt из скрипта
Обработку ошибок через $?
Функции с возвратом значений


Этапы:

Shebang + цвета
Проверить что запущен от root
Обновить список пакетов (apt update)
Читать packages.txt построчно
Устанавливать каждый пакет
Проверять $? — успех или ошибка
Лог результатов

Следующая цель — скрипт мониторинга доступности сайтов.
Что будет делать:

Читать список сайтов из файла sites.txt
Проверять каждый через curl
Если сайт недоступен — выводить предупреждение
Писать результат в лог с датой

По пути освоишь:
Цикл while read для чтения файла построчно
curl с флагами для проверки HTTP кода
Работу с exit кодами $?
Форматированный вывод таблицей

Этапы:
Shebang + цвета
Проверить что файл sites.txt существует
Цикл — читать сайты из файла построчно
Для каждого сайта получить HTTP код через curl
Проверить код — 200 это ОК, остальное — ошибка
Вывод результата + лог

Скрипт бэкапа папки

    Принимать папку как аргумент $1
    Проверять что папка существует
    Архивировать через tar с датой в имени файла
    Писать результат в лог

Shebang + переменные цветов #!/bin/bash
Проверить что пользователь передал аргумент $1
Проверить что папка существует (-d)
Создать архив через tar с датой в имени
Проверить что архив создался успешно ($?)
